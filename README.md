 Описание

Простое приложение для борьбы с прокрастинацией. Программа случайным образом выбирает для вас задачу из предопределенных списков (Учёба, Спорт, Работа) или из добавленных вами собственных. История сгенерированных задач сохраняется между запусками.

Требования

  Python 3.x
  Стандартная библиотека `tkinter`
    Стандартная библиотека `json`
  Git (для контроля версий)

 Запуск программы

1.  Установите Python (если он еще не установлен).
2.  Скачайте или клонируйте этот репозиторий.
3.  Запустите скрипт из корня проекта:
    ```bash
    python main.py
    ```
4.  Нажмите кнопку «Сгенерировать задачу».
5.  Чтобы добавить свою задачу — введите текст и выберите категорию.
# Возможные тесты (Примеры использования)

Для проверки корректности работы программы выполните следующие действия:

1.  Проверка генерации: Нажмите кнопку «Сгенерировать задачу» несколько раз. Текст в главном окне должен меняться на случайный элемент из списка.
2.  Проверка фильтрации:
    *   Выберите фильтр «Спорт» в выпадающем списке.
    *   Сгенерируйте задачу. Она должна относиться только к спорту.
3.  Проверка добавления задачи:
    *   Введите текст «Помыть посуду» в поле ввода.
    *   Выберите категорию «Работа» (или любую другую).
    *   Нажмите «Добавить в список».
    *   Сгенерируйте задачу снова — «Помыть посуду» должна появиться среди вариантов.
4.  Проверка валидации: Попробуйте нажать «Добавить в список», оставив поле пустым. Программа должна показать окно с ошибкой.
5.  Проверка истории: Сгенерируйте несколько задач. Закройте программу и запустите снова. История в нижней части окна должна сохраниться.
